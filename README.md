# 古典音乐作曲家世界杯

一款以 48 位古典音乐作曲家为参赛者的互动选择游戏。玩家可以试听代表作片段，在小组赛、复活赛和淘汰赛中逐轮选择，最终产生自己心目中的作曲家世界杯冠军。

## 比赛流程

1. 48 位作曲家随机进入 12 个以十二平均律音级命名的小组，每组 4 人。
2. 每组选择 2 位作曲家直接晋级。
3. 从小组赛淘汰的 24 人中选择 8 位复活。
4. 32 位作曲家进入淘汰赛，经过逐轮对决产生冠军。
5. 完成后可以查看完整晋级路线并下载结果图片。

## 主要功能

- 作曲家的中英文姓名、肖像、生卒年份、国家、时期和简介
- 中英文代表作及 30 秒在线试听
- 随机分组、小组赛、复活赛和完整淘汰赛
- 浏览器自动保存比赛进度
- 桌面端与移动端自适应布局
- 最终赛果图片下载

## 本地运行

```bash
npm install
npm run dev
```

## 数据与音频

作曲家资料主要依据公开百科资料整理。肖像主要来自 Wikimedia Commons，试听片段通过公开音乐目录的在线接口匹配。第三方资源的可用性可能受到地区、曲目版本和版权状态影响。

## 隐私

比赛选择和进度保存在玩家自己的浏览器中，不建立用户账户，也不会自动上传比赛结果。

## 致谢

项目构思参考了“诗经世界杯”和“中国古代诗人世界杯”的互动比赛形式，并将其改编为古典音乐主题。
